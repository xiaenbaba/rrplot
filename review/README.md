历史问题和测试数字不代表当前版本；现行架构、实施进度和变更分别见
[架构说明](../docs/ARCHITECTURE.md)、[实施路线](../docs/plans/ROADMAP.md)和
[变更记录](../CHANGELOG.md)。

## 存放约定

- 后续评审文档统一放在本目录，建议命名为 `review-YYYYMMDD.md`；专项评审可
  使用 `review-YYYYMMDD-主题.md`。
- 新增报告时更新本索引，正文注明评审日期、基线和整改状态。
- 当前架构位于 `docs/ARCHITECTURE.md`，路线图和计划位于 `docs/plans/`；
  使用相对链接引用这些现行文档，避免与历史评审混淆。
