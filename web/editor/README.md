# 编辑器控制器

`../app.js` 是浏览器入口，只有创建、绑定、启动三个动作。`index.js` 是
组装位置：先建立 `state`，合并每个工厂返回的命名命令，再绑定事件并启动。
不增加框架、构建步骤或浏览器运行依赖。

| 模块 | 负责内容 |
| --- | --- |
| state / config | 实例内可变状态；存储键与纯工具常量 |
| session | 选择、挂接同步、解析调度、编辑事务与文档撤销/重做 |
| files | 异步载入/取消、替换确认、草稿历史、JSON 保存/下载确认 |
| export | 正式预览、图像资源释放、缩放及 SVG/PNG/PDF 导出 |
| canvas / viewport | SVG 渲染和临时辅助层；坐标、边界、缩放、定位 |
| connections | 连线预览/校验、三通插入/分支及端点重接 |
| routing | 按所选/整图运行避障事务，进度、取消、过期结果保护及单次撤销 |
| coordinates | 折点坐标窗口、窗口内历史、导入/复制和走线预览 |
| pointer / keyboard | 指针拖动、图元拖放；快捷键、连续微调和取消 |
| selection | 增删/复制/粘贴、平移、对齐/分布和纸张排版 |
| inspector / styles | 属性字段和分组；批量样式窗口 |
| sidebar | 图元/模板筛选、对象查找、图纸检查与定位 |
| events | 页面动作表、跨标签页存储通知和通用页面事件 |
| ui / startup | DOM/通知/接口恢复；目录与模板初始化、独立基准适配 |

## 修改约定

- 控制器工厂签名为 `(state, commands)`，只返回函数。共享可变值统一放在
  `state`，不要复制图纸、历史栈或连接状态到模块全局。
- `commands` 是实例内的命名调用接口。控制器之间不互相导入，跨模块调用
  使用 `commands.name(...)`；底层纯函数继续静态导入。新增命令在工厂返回
  值中声明，由 `index.js` 组装，原生模块测试会检查所有命名调用均存在。
- 事件放在所属控制器的 `bind...Events()` 中，在所有命令就绪后调用。
  总入口 `bindEvents()` 可重复调用，实际仅绑定一次；工厂本身不读草稿或
  发起网络请求，不创建隐式的第二份编辑器状态。
- 文档修改通过 `edit()` / `finishEdit()` / `history()`，保留单次操作对应
  单次撤销。拖动中的本地反馈仍可直接更新当前文档，在结束时统一提交。
- 异步结果继续检查 revision、request 或窗口 session。不要省略保存完成
  确认、关闭预览释放 URL、取消载入、保留他页草稿等现有保护。
- 不在页面暴露测试接口。`tests/web_editor_harness.cjs` 只为既有 VM 场景
  映射旧状态名和可替换副作用；另有原生 ESM 测试覆盖实际模块路径和组装。

运行 `tests/test_web_editor_modules.py` 可快速检查模块契约；修改具体功能后
再运行对应的 `test_web_*.py`。跨状态或事件流程的重构应运行全量回归，并在
独立服务以测试图纸验收，不覆盖用户页面中的草稿。

## 画布性能约定

- 通过 `canvasRenderer` 排序和批量挂入新分组，避免提前挂入半成品。
  带背景文字必须在分组提交后读 `getBBox()`，并先读完所有边界再写背景。
- 图元定义按 image/glyphId 和 box 区分，节点模板最多 64 份、仅保留当前场景；
  克隆时必须重写端口 `data-ref.nodeId`，不能把前一个设备的端口带到副本。
- 避免在每次重绘末尾测量 SVG 容器；视图变化/ResizeObserver 负责刷新宽度。
  载入使用先 fit 后 render，保留同步提交、原有版本保护与撤销语义。
- `test_web_editor_rendering.py` 运行真实控制器和缓存，检查共享定义、端口归属、
  未变化 DOM 的身份、缓存回收、文字测量时序以及视图宽度刷新。
