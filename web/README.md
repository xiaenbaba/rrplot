# rrplot 浏览器编辑器

使用仓库已有 Python 环境即可运行，无新增运行依赖，不需要 npm、Node.js 或构建前端。

## 启动

Windows 下可以双击仓库根目录的 `start-web.cmd` 启动。
使用编辑器期间请保持该窗口打开，关闭窗口或按 Ctrl+C 会停止服务。

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe server\run.py
```

打开 <http://127.0.0.1:8765>。更换端口可加 `--port 8766`。按 Ctrl+C 停止服务。
也可从其他目录用 Python 和 `server/run.py` 的绝对路径启动。
服务只绑定 `127.0.0.1`，适用于本机单用户，不需要数据库。

如果尚未安装项目依赖，请先按仓库 README 安装 rrplot；Web 端复用 Matplotlib 和 numpy。
直接通过 `file://` 打开页面无法调用绘图接口。
如果浏览器提示“拒绝连接”或“无法访问此网站”，先重新启动服务，再刷新页面。
网页文件存在并不表示本机 HTTP 服务正在运行。
同一端口只运行一个服务；重复运行 `start-web.cmd` 时，如果检测到已有 rrplot 服务，会直接提示服务地址。要加载代码或模板更新，请先在原服务窗口按 Ctrl+C，再重新运行脚本；如果端口被其他程序占用，可使用 `start-web.cmd --port 8766`。

## 编辑图纸

1. 左侧点击“模板”，选择普通热泵、带气液分离器的普通热泵、EVI 过冷器、FTVI 闪蒸罐、EVI 中间换热器或四通阀热泵（制热/制冷）模板，也可以新建空白图纸。
2. 点击图元库的设备，再点击画布放置；也可从图元库拖入画布。
3. 选择设备并拖动，或在属性面板输入坐标、尺寸、画法、方向和旋转角。
4. 切换“连线”工具，依次点击起点、终点端口或三通；选中起点后会显示虚线预览，靠近端口或三通会自动吸附。移动设备后，连线按端口重新计算。
5. 选中管线，拖动线段中间的长条手柄调整走线：水平段上下拖，垂直段左右拖，端口连接和引出段保持固定。双击管线增加方形折点，拖动折点改变路径；Alt+点击折点删除。
6. 切到“三通”工具，点击管路可在点击位置插入分支点，Shift+点击管路可插入后立即接出支路，点击空白可独立放置；选择管线或三通后，也可从属性面板开始接管。
7. 选择模式下依次点两个端口，在左侧“端口对齐”中选择水平或垂直对齐，移动第二个对象。
8. 文字工具添加独立标签；设备属性可添加附着标签。设备附着标签随设备移动和旋转；选中管路后可“添加状态点”，让编号或参数文字随管路调整。标签支持拖动偏移、字号、对齐和白色背景。
9. 按住 Shift 点击多个设备、管路、三通或文字可多选；拖动已选设备、三通或文字按同一位移批量移动，管路按端点跟随。附着标签随设备移动，避免重复位移。
10. 多选后，属性栏“批量布局”提供左/中/右、上/中/下对齐，以及水平/垂直等距分布；每次操作可撤销。

### 阀件挂接

参考同级 rrhpwh 的操作方式，支持将膨胀阀、截止阀、电磁阀、单向阀、过滤器、毛细管和消音器挂在完整管路上，无需先切断管路。

- 从图元库拖到管路，或选好图元后在管路附近点击放置；18 个屏幕 CSS 像素内出现绿色圆环，松开或点击完成挂接，缩放不影响吸附距离。已有的独立阀件也可拖到管路挂接。
- 图元库拖放使用指针捕获，圆环单独更新，不重建整张画布；经过管线或图元时保持预览。按 Esc 取消，拖到画布外松开不会放置；普通点击图元仍进入点击放置模式。
- 选中挂接阀件，在属性栏选择“挂接管路”、输入“挂接位置（%）”，或勾选“挂接反向”。百分比按所属管路从起点到终点的总路径长度计算；拖动阀件可沿管调整，移到另一条管路可重新挂接。
- 移动管路端点设备、三通或编辑折点时，阀件按比例随管移动和转向。拖离管路或点击“解除挂接”，保留当前位置并恢复独立设备端口；直接对阀件做坐标平移或批量对齐也会解除挂接。
- 删除附件保留整条管路；删除所属管路时，附件在原位解除挂接。三通分段、删除两接管三通合并、反转管路时保留附件位置和方向。复制设备组及组内管路会带上附件；只复制阀件则生成独立副本。
- 支持 Ctrl+Z / Ctrl+Y、JSON 保存与重开，以及正式预览和 SVG / PNG / PDF 导出。阀体下方管线及箭头被遮挡，避免穿过符号。

挂接仅表示绘图附件，不拆分父管路或计算阻力。已经用独立管路接好端口的阀件不允许同时挂接，旧模板和图纸也不会自动转换。升级后需重启 Python 服务，先保存当前 JSON，再 Ctrl+F5 加载新版页面。

### 连线与接管

连线和端点重接时，鼠标距端口或三通中心 12 个屏幕 CSS 像素以内即可吸附，
画布放大或缩小后仍保持相同的操作距离。起点、终点和重接共用此规则，
悬停预览与实际点击使用同一目标；直接点中接点优先，否则选择范围内最近的接点。
同一设备上重合的端口别名按一个物理端口处理。最近接点不可连接时显示原因，
不会跳过它连接到另一接点。“吸附”复选框只控制网格吸附，不关闭接点吸附；
选择模式不使用附近接点，空格拖动和鼠标中键仍优先平移视图。

切换“连线”后，尚未选定起点时，靠近接点也会显示绿色圆环和“点击起点：设备名称 · 端口”提示；
点击后再靠近终点，显示下述连接校验结果。起点提示仅用于确认接点，不表示已完成接管；
此时不绘制管路预览，移开接点、离开画布、切换工具或按 Esc 会清除提示。

连线模式下，普通点击设备主体、文字或管路不会改变选择或拖动对象，
双击管路也不会增加折点。拖动空白仍可平移视图，并保留已选起点；
需要移动设备或修改走线时，先按 Esc 或切换“选择”工具。

连线和端点重接会在提交前检查：起终点位于同一位置时拒绝连接；端点及完整走线
与已有管路相同时提示重复，忽略箭头方向、线宽及颜色。相同端点但走线不同的并行管路可保留，
几何交叉或接触不会自动成为连接。需要分支时请使用明确的三通。
使用“三通”工具点击管路，分支点会落在该管路距点击位置最近的点上，不按网格偏移；
悬停时对应管路高亮，并在实际插入位置显示绿色圆环及 X/Y 坐标；点击后落点与预览一致。
三通工具及 Shift 接管/重接时，靠近管路 12 个屏幕 CSS 像素内即可吸附，不必精确点中细线；
距离不随画布缩放改变。直接点中的管路优先，否则选择最近管路，等距时按图纸顺序稳定选择；
最近目标无效时显示原因，不跳过它插入其他管路。设备和文字主体不触发附近管路吸附，
连线及重接仍优先使用附近已有端口或三通。“吸附”复选框只控制网格，不关闭管路吸附。
三通工具在距离管路超过 12 像素的空白处仍独立放置；选择模式与普通连线不使用管路吸附。
端点、零长管路或分段后折点超限时显示红色预览及原因，点击不会修改图纸。
移出管路吸附范围、离开画布、切换工具、按 Esc 或缩放/平移视图后清除预览；悬停预览不写入草稿或撤销记录。
原管路分成两段，走线、样式和状态点位置保持，完成后回到选择模式，可切换“连线”接出支路。
交叉处只拆分实际点中的一条管路，另一条仍不相连；需要连接多条管路时，请将其端点重接到同一三通。
三通工具靠近已有端口或三通 12 个屏幕像素以内时，优先显示原接点。普通点击已有三通
将其选中，Shift+点击则直接从该三通接出支路，不增加三通、管路或撤销记录；完成支路后
只需一次撤销即可移除新管路。设备端口附近显示红色提示，请切换“连线”使用原端口，
不会插入重叠三通。网格取整后与已有接点重合时也采用相同保护，预览与点击保持一致。
点击设备或文字主体不会拖动对象或放置三通；端点处请直接使用原接点。
空白处独立放置仍使用网格吸附，属性栏“在管路中间插入三通”仍按路径长度中点插入。
一次插入可用 Ctrl+Z 撤销、Ctrl+Y 重做；删除两接管三通可恢复管路。

需要插入后直接接管时，在“三通”工具下按住 Shift 点击管路，系统会插入三通并自动选为连线起点，
再点击终点端口或三通完成支路。也可选中管路，在属性栏点击“插入三通并接出支路”，按路径长度中点插入；
选中已有三通后，点击“从此三通接出支路”即可继续接管，开始接管本身不修改图纸或增加撤销记录。
当前连线、重接、放置或拖动尚未结束时，请先完成操作或按 Esc，再从属性栏接出支路。
按 Esc 取消连线会保留已插入的三通；无效终点被拒绝后保留起点，可直接选其他终点重试。
插入和接管分别记录撤销：完成支路后，第一次 Ctrl+Z 撤销支路，第二次撤销插入并恢复原管路；
撤销或重做不会自动恢复未完成的接管会话。

也可从支路另一端开始：切换“连线”，选好设备端口或已有三通作为起点，按住 Shift 悬停目标管路，
确认高亮管路、接入圆环和 X/Y 坐标后，Shift+点击即可自动插入三通并接好支路。
接入点按管路投影确定，不按网格偏移；附近 12 个屏幕 CSS 像素内已有端口或三通时，优先复用该接点。
自动插入与接管共用一次撤销，Ctrl+Z 恢复整次操作；取消预览不会留下新三通。
同位置、重复走线、无效插入位置或对象数量超限时显示红色提示，点击拒绝且保留起点，
可选择其他位置或普通端口重试。交叉处只拆分实际点中的管路；仅跨过管路不自动连接。
松开 Shift、移离画布、缩放或平移后清除接入提示；普通点击管路不插入三通。

也可直接从主管开始，无需先切换“三通”：切换“连线”，尚未选择起点时，按住 Shift 靠近管路，
确认高亮和插入圆环后 Shift+点击，自动插入三通并将其作为连线起点。再点击端口或已有三通，
也可 Shift+点击另一条管路完成接管；附近已有接点时优先复用，不重复插入。
插入和接管分成两次撤销：第一次撤销支路，第二次撤销起点三通并恢复主管；
Esc 取消未完成的连线会保留已插入三通，Ctrl+Z 可撤销插入。只悬停或松开 Shift 不修改图纸。
三通插入和新接管均检查 2000 项数量上限，超限时拒绝并保留当前连线起点供调整后重试。

新连线也可边画边指定走线：选好起点后，按住 Alt 点击画布空白处添加折点，
继续 Alt+点击可增加折点，Backspace 回退最后一个折点。折点位置遵循“吸附”网格设置，
画布以小方框标记已指定位置，并预览从起点经这些折点到鼠标或终点的正交走线；
没有折点时沿用原自动走线。点击端口或三通，或 Shift+点击另一条管路完成，
折点随整条新支路一次保存、撤销及导出；若从主管插入起点三通，插入仍是单独一次撤销。
最多 100 个折点，拒绝与上一点重合或超出坐标范围的位置；无效终点后保留起点和折点供重试。
Esc 或切换工具会取消全部临时折点，不写入草稿；缩放、平移或离开画布不会丢弃已指定折点。
连线等待终点时，Delete 不删除所选设备，Backspace 只回退折点。
普通空白拖动仍平移视图；Alt+点击设备或文字主体不添加折点，端口/三通仍按连接处理。
完成前也可直接拖动这些小方框调整临时折点，或 Alt+点击某个方框删除指定折点，
不必从最后一个逐次回退。拖动使用网格吸附，拒绝与前后相邻点重合和超出坐标范围的位置。
拖动过程中按 Esc 仅取消本次拖动并恢复原折点，保留连线起点；再按 Esc 取消整次连线。
窗口失焦、指针取消或捕获丢失也恢复该次拖动，普通松开鼠标保留调整结果；
移动和删除临时折点不会写入草稿或增加撤销记录，最终管路整体提交一次历史。
选定起点后，画布上方出现“当前连线操作”栏，显示临时折点数量。
可点击“回退折点”删除最后一个，或“清空折点”保留起点并恢复自动走线；
“取消连线”返回选择模式，已插入的起点三通保留，可 Ctrl+Z 撤销。
没有折点时回退和清空按钮禁用；拖动或按空格平移期间三个按钮暂时禁用。
回退后剩余折点和走线预览继续保留，按钮操作后焦点回到画布，可继续用快捷键。
已有临时折点时，点击“编辑坐标”打开坐标列表，按起点到终点顺序输入各点的 X/Y。
使用图纸坐标，X 向右、Y 向下为正，支持小数；精确输入不受网格吸附影响。
点击“应用坐标”一次更新全部临时折点并继续连线；取消或 Esc 保留原有折点。
空坐标、越界及相邻点重合会阻止应用，可在窗口内修正。预览会在首个出错折点下方显示原因并标红相关输入；点击“应用坐标”会自动滚动并聚焦到该行，数值错误定位到对应 X/Y，几何重合定位到该行 X。输入修正后提示自动清除，预览恢复；重复走线或图纸变化等整体错误仅在窗口提示，不标记无关折点。
若当前连线或图纸已变化，请关闭窗口重新打开。输入、取消及应用均不写入图纸历史或草稿，最终完成连接时整体保存。
已有管路重接继续保留原折点，新折点请在完成重接后编辑。
已有管路也支持精确输入：切回“选择”，单选一条管路，在右侧点击“编辑折点坐标”。
没有手动折点也能打开，点击“末尾添加折点”后输入 X/Y；按起点到终点顺序修改，支持小数，不受网格吸附影响。
坐标窗口内可在任一折点前插入新行，或删除指定折点，自动重新编号；添加的新行需填写两个坐标。
每行“上移 / 下移”可将该折点与前后相邻行交换，坐标成对移动，保留未应用的小数或空输入。
第一行禁用上移、最后一行禁用下移；排序后重新编号并更新走线预览，点击应用后才生效，取消或 Esc 放弃排序。
窗口标题、取消及底部应用操作固定显示，说明、走线预览和折点列表共用一个滚动区域；长列表或窄屏下无需滚到底部即可应用。
底部“清空列表”一次移除窗口内全部折点；“恢复原坐标”恢复打开本次窗口时的折点数量、顺序及坐标，也可撤回未应用的清空、增删和排序。两项操作均先更新列表和预览，点击“应用坐标”后才生效；取消或 Esc 放弃修改。清空后应用恢复自动走线，已应用的修改需用 Ctrl+Z 撤销。
已有输入会保留，最多 100 个折点。临时连线和已有管路共用此操作，全部修改点击“应用坐标”后才生效。
删除所有行后应用，恢复自动走线；临时连线保留起点，已有管路仍保留端口。取消或 Esc 放弃本次增删和输入。
坐标窗口内实时显示灰色原走线与绿色新走线，输入或增删后更新；圆点标记起点/终点，少量折点显示序号。
点击预览中的手动折点，自动滚动并聚焦到对应行的 X 输入；也可用 Tab 选中预览折点，按 Enter 或空格定位。聚焦任一 X/Y 输入时，对应行和预览折点同步高亮；修改坐标后高亮保持，预览不抢输入焦点。联动仅定位窗口内的输入，不修改图纸、临时连线或撤销历史；无效走线隐藏预览，修正后恢复。
底部固定的“上一折点 / 下一折点”按当前列表顺序定位到前后行的 X 输入，“定位到折点”下拉列表可直接跳至任一行。编号和总数随增删、排序、清空及恢复同步更新，首尾禁用越界按钮，空列表禁用全部定位控件。定位保留尚未应用的小数或空输入，不修改坐标、走线和历史；即使坐标错误导致预览隐藏，仍可定位其他行继续修正。
窗口顶部“撤销输入 / 重做输入”可恢复尚未应用的坐标输入、增删、排序、清空和恢复操作，同一输入框连续输入合并为一步（失焦或确认输入后分开记录），最多保留 100 步；保留空值、小数文本及当前定位，恢复后同步预览和校验。新修改会清除重做，纯定位不增加历史。窗口历史仅在本次打开期间有效，取消或应用后清空；不会改变图纸和画布撤销记录。已应用的管路修改仍用画布 Ctrl+Z 撤销，输入框自身的键盘撤销由浏览器处理。
已有管路预览起点至终点的完整路径，临时连线只预览起点至最后折点，终点仍待选择。

## 页面排版

## 管路状态点

## 保存、预览与恢复

- “保存 JSON”保存可再次编辑的完整图纸。支持原生保存窗口的浏览器会让你选择位置，文件写入完成后才清除未保存标记和当前草稿；取消或失败会保留修改与草稿。每次保存均选择目标文件，不会静默覆盖。
- 不支持原生保存窗口时，使用浏览器下载，并显示“确认已保存 / 暂不确认”。检查 JSON 文件已保存后再确认；确认前保留未保存标记和草稿。“暂不确认”仅收起提示，后续可重新保存。
- 保存期间按钮显示“保存中…”并阻止重复提交。保存的是点击时的快照；期间继续修改或替换图纸，当前图纸不会被旧保存结果标为已保存，下载确认提示也会随新修改失效。
- “打开 JSON”从本机恢复，非法图纸会显示原因并保留当前图纸。
- 新建、打开 JSON 和载入模板共用载入保护，先确认未保存修改，再读取并校验目标图纸。载入提示显示目标名称，可点“取消载入”；继续编辑、输入图纸属性或撤销重做会取消旧载入，保留当前修改。快速切换时只允许最近一次载入生效，同一模板等待期间重复点击不重复请求。
- 载入失败保留当前图纸、草稿和撤销记录。拖动、放置、连线、重接或页面排版期间请先完成操作或按 Esc；弹窗打开时不能开始另一项载入。取消会忽略后续结果，已经发出的本机请求可能仍会完成。
- “正式预览”调用 rrplot/Matplotlib 输出整图；PNG、SVG、PDF 使用同一输出模型，不带网格、端口和选中框。
- 修改后自动写入当前浏览器的本机草稿。顶部“草稿”可随时查看名称、保存时间及设备/管路数量，并选择恢复；启动提示中的“暂不恢复”只收起提示，仍可从顶部进入。
- 首次编辑会在覆盖上次会话或其他标签页的草稿前，将其放入历史，最多保留最近 5 份历史草稿及当前自动草稿，相同内容去重。连续编辑当前图纸不会每次生成历史；超出 5 份时淘汰最早的历史。恢复前校验图纸，失败保留当前图纸；恢复成功后仍需保存 JSON。
- 草稿仅在相同浏览器和服务地址中可用，更换端口或浏览器会使用不同存储。草稿不会上传云端，且不替代 JSON 文件备份；存储不可用或空间不足时显示“草稿未保存”，保留原有草稿，请立即保存 JSON。
- 有未保存修改时，替换图纸或关闭页面会提示。草稿的可用性取决于浏览器存储，清理浏览器数据会删除草稿。
- 当前修改成功写入 JSON、确认下载已保存或确认替换图纸后，只清除当前页面自己记录的自动草稿，历史草稿保留；替换确认中选择“继续编辑”可保留当前修改。启动时尚未恢复的草稿及其他标签页新写入的草稿，不会被保存或切换模板操作直接清除。恢复历史草稿时，现有自动草稿也会先进入历史。

普通滚轮保留滚动查看；放大后也可使用窗口内的水平、垂直滚动条。
手动缩放范围为 10%～800%；“100%”按 SVG 原始 CSS 像素尺寸显示，与 PNG 导出的 DPI 设置独立。

“适应窗口”显示整张纸面，并在调整窗口大小时重新适配；手动缩放后保持所选比例。
缩放和滚动只改变预览视图，不改变编辑画布、纸面尺寸、图元比例、草稿、保存状态或撤销记录。
关闭按钮或 Esc 可结束预览并释放图片资源；加载中也可关闭，稍后返回的结果会被丢弃。
失败时窗口内显示原因，点击“重新生成”重试；图纸版本变化后不展示旧结果。

JSON 使用 `schemaVersion: 1`，设备保存工厂参数，管线保存设备/端口 ID 和控制点。
管路状态点仍保存在 `labels`：`edgeId` 引用管路，`at` 为 0～1 的路径长度比例，`x/y` 为页面方向的偏移；同一标签不能同时设置 `nodeId` 和 `edgeId`。
图元与端口来自现有 Python 工厂；导出前重新解析整个图纸，避免旧坐标缓存。
中文字体和字号效果以“正式预览”为准。

## 图纸检查

点击顶部“检查”，读取当前图纸的连接关系和页面边界，列出以下待核对项：

- 未连接任何管路的设备，以及未接管或仅接一条管路的三通。
- 管路两端引用同一物理端口或三通，或两端重合导致管路长度为零。
- 端点和完整走线均相同的管路，忽略流向与样式；端点相同、走线不同的并行管路允许保留。
- 设备外框、三通、文字或管路走线超出页面。

点击一条结果，会选中对应对象、将视图移到该位置并打开属性；可修改位置、重接端点或按需要删除，再次点击“检查”更新结果。
检查和定位不会移动图纸对象、修改 JSON 或增加撤销记录；关闭弹窗或按 Esc 可返回编辑。结果只在本次检查中显示，最多显示前 100 项。
设备的备用端口不要求全部接管；两个接管的三通允许作为管路中的过渡点。端口别名按同一物理接管处理。
检查不包含设备避障、系统完整性和热力正确性计算；列出的问题需要结合图纸用途确认。
本次为前端更新，保存 JSON 后按 Ctrl+F5 加载；服务须具备当前图纸使用的图元和状态点功能。

## 快捷键

草稿与 JSON 保存说明。帮助可通过关闭按钮或 Esc 关闭，打开帮助不修改图纸或选择。
每次重新打开帮助会回到顶部，方便查看单键开关和开始绘图说明。
服务尚未连接时，帮助入口也可用。

帮助窗口的“启用单键快捷键”可关闭 V/B/M/C/J/T/?，关闭后仍可点击顶部“?”进入帮助重新开启。
设置仅保存在当前浏览器与服务地址，不写入图纸、草稿或撤销记录；同地址其他标签页会同步更新。
