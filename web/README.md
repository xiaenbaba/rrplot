# rrplot 浏览器编辑器

使用仓库已有 Python 环境即可运行，无新增运行依赖，不需要 npm、Node.js 或构建前端。

## 启动

Windows 下可以双击仓库根目录的 `start-web.cmd` 启动。
使用编辑器期间请保持该窗口打开，关闭窗口或按 Ctrl+C 会停止服务。

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe server\run.py
```

打开 <http://127.0.0.1:8765>。更换端口可加 `--port 8766`。按 Ctrl+C 停止服务。
也可从其他目录用 Python 和 `server/run.py` 的绝对路径启动。
服务只绑定 `127.0.0.1`，适用于本机单用户，不需要数据库。

如果尚未安装项目依赖，请先按仓库 README 安装 rrplot；Web 端复用 Matplotlib 和 numpy。
直接通过 `file://` 打开页面无法调用绘图接口。
如果浏览器提示“拒绝连接”或“无法访问此网站”，先重新启动服务，再刷新页面。
网页文件存在并不表示本机 HTTP 服务正在运行。
同一端口只运行一个服务；重复运行 `start-web.cmd` 时，如果检测到已有 rrplot 服务，会直接提示服务地址。要加载代码或模板更新，请先在原服务窗口按 Ctrl+C，再重新运行脚本；如果端口被其他程序占用，可使用 `start-web.cmd --port 8766`。

## 编辑图纸

1. 从左侧选择普通热泵、带气液分离器的普通热泵、EVI 过冷器、FTVI 闪蒸罐或 EVI 中间换热器模板，也可以新建空白图纸。
2. 点击图元库的设备，再点击画布放置；也可从图元库拖入画布。
3. 选择设备并拖动，或在属性面板输入坐标、尺寸、画法、方向和旋转角。
4. 切换“连线”工具，依次点击起点、终点端口或三通；选中起点后会显示虚线预览，靠近端口或三通会自动吸附。移动设备后，连线按端口重新计算。
5. 选中管线，拖动线段中间的长条手柄调整走线：水平段上下拖，垂直段左右拖，端口连接和引出段保持固定。双击管线增加方形折点，拖动折点改变路径；Alt+点击折点删除。
6. 三通工具可独立放置分支点；选择管线后，属性面板可在中间插入三通，再连接支路。
7. 选择模式下依次点两个端口，在左侧“端口对齐”中选择水平或垂直对齐，移动第二个对象。
8. 文字工具添加独立标签；设备属性可添加附着标签。设备附着标签随设备移动和旋转；选中管路后可“添加状态点”，让编号或参数文字随管路调整。标签支持拖动偏移、字号、对齐和白色背景。
9. 按住 Shift 点击多个设备、三通或文字可多选；拖动任意已选对象，会按同一位移批量移动。附着标签随设备移动，避免重复位移。
10. 多选后，属性栏“批量布局”提供左/中/右、上/中/下对齐，以及水平/垂直等距分布；每次操作可撤销。

点击“框选”，在画布拖出矩形，可一次选中完整框住的设备、三通和文字，向任意方向拖框均可。
松开后自动回到“选择”，拖动任意已选对象即可一起移动，或在属性栏对齐、均匀分布。
选择模式下按住 Shift 从空白处拖动可追加框选，Shift+点击可取消某一项。
框选期间按 Esc 恢复原选择；框选不会移动视图或修改图纸，也不占用撤销记录。

多选后点击“复制”或按 Ctrl+D，会向右下偏移 20 单位复制整组对象，包含设备附着标签，
以及两端均在组内的管路和手动折点。副本保持选中，可直接整组拖动；组内折点随对象一起移动。
单独复制旋转设备上的标签时，标签保持附着，按页面的右下方向偏移。
点击“删除”或按 Delete / Backspace 删除全部选择，同时清理被删设备的标签和关联管路。
删除管路中间的两接管三通会恢复管路；删除仍有三条及以上接管的三通会移除这些关联管路。
一次复制或删除对应一次撤销，可用 Ctrl+Z / Ctrl+Y 撤销或重做。

U 型管气液分离器的 `in` 为顶部短管入口，`out` 为 U 型管出口，
`drain` 为底部排液口。属性中的“镜像进出管”可交换左右进出管位置，
“接管长度”同时更新外形和端口。带气液分离器模板将出口与压缩机吸气口垂直对齐。

窄窗口中用工具栏的“图元”和“属性”打开侧栏，再次点击关闭。滚轮缩放，空白拖动平移，
“适应画布”恢复全图；按住空格或鼠标中键也可平移。网格显示与网格吸附可分别开关。

要改变整张系统图在纸面中的位置，点击“整体移动”（或在非输入框中按 Ctrl+A），
在画布任意位置按住左键拖动。设备、三通、管路折点和文字同步移动，连接关系与相对布局保持不变。
吸附开启时按统一位移吸附，关闭后可自由移动。每次拖动对应一次撤销，可用 Ctrl+Z / Ctrl+Y 撤销或重做。
拖动中按 Esc 取消本次移动；松开后按 Esc 或点击“选择”退出。纸张和视图位置不变，保存与导出会保留移动结果。

管线交叉不代表连通；使用显式三通建立支路。路由保持直角并沿端口法向引出，
目前不会自动绕开设备，复杂管路需要手动控制点。编辑器不进行制冷循环或热力正确性计算。

线段拖动遵循“吸附”开关，直管移动后自动增加直角折弯。过短线段和固定端口引出段不显示长条手柄。
每次拖动对应一次撤销；拖动中按 Esc 取消，属性栏的“清除折点”可恢复自动走线。

## 管路端点重接

选中已有管路，在右侧点击“重接起点”或“重接终点”，再点击新的设备端口或三通。
重接期间端口显示并可吸附，原管路淡显，虚线预览保留原有折点的新走线；点击空白不会修改图纸，按住空格或鼠标中键可平移视图。
点击有效端点后完成重接，管路 ID、线型、颜色、箭头、折点和附着状态点保持，状态点按原路径比例跟随新走线。

按 Esc 或点击“取消重接”可退出，保持原连接且不增加撤销记录。选择原端点也不增加撤销记录；管路两端不能连接到同一位置。
一次重接可用 Ctrl+Z 撤销、Ctrl+Y 重做；重接期间请先完成或取消，再复制、删除对象。
跨设备重接仍保留原手动折点，可继续拖动管段调整，或点击“清除折点”恢复自动走线；路由不会自动避开设备。
本次为前端更新，已有新版服务可在保存 JSON 后按 Ctrl+F5 加载；如页面提示管路状态点需要新版服务，请按下节说明重启服务。

## 管路状态点

选中管路，在右侧属性中点击“添加状态点”，自动生成当前未使用的最小正整数编号。
选中状态点后，可将“标签内容”改为编号、温度、压力等文字；“沿管路位置（%）”按起点到终点的总路径长度定位，0 为起点、100 为终点。
“相对偏移X/Y”按页面方向调整文字与管路锚点的距离，X 向右、Y 向下；也可直接拖动文字调整偏移。

已有独立文字可通过“附着管路”下拉框绑定管路，选择“独立文字”解除绑定，两种操作均保持文字当前页面位置。
移动设备、拖动管段或调整折点后，状态点会按路径长度比例跟随；管路反向、插入三通及删除两接管三通恢复管路时，状态点保持原位置。
复制整组设备时同时复制组内管路及其状态点；单独复制状态点仍附着原管路。删除管路会同时删除其状态点，操作支持撤销重做。
模板原有编号保持原来的标签类型，可按需要手动附着。状态点随 JSON 保存、重开，并输出至正式预览和 PNG/SVG/PDF。

此功能需要新版 Python 服务。更新后先保存 JSON，在原服务窗口按 Ctrl+C 停止服务，再运行 `start-web.cmd`，最后在浏览器按 Ctrl+F5。
旧服务未重启时，页面会提示并禁用管路附着设置。

## 保存、预览与恢复

- “保存 JSON”下载可再次编辑的完整图纸；“打开 JSON”从本机恢复，非法图纸会显示原因并保留当前图纸。
- “正式预览”调用 rrplot/Matplotlib 输出整图；PNG、SVG、PDF 使用同一输出模型，不带网格、端口和选中框。
- 修改后自动写入当前浏览器的本机草稿。重新打开页面后可点击“恢复草稿”。草稿不会上传云端，且不替代 JSON 文件备份。
- 未下载 JSON 时，替换图纸或关闭页面会提示。草稿的可用性取决于浏览器存储，清理浏览器数据会删除草稿。
- 保存 JSON 或确认替换图纸后，会清除旧草稿；替换确认中选择“继续编辑”可保留当前修改。

JSON 使用 `schemaVersion: 1`，设备保存工厂参数，管线保存设备/端口 ID 和控制点。
管路状态点仍保存在 `labels`：`edgeId` 引用管路，`at` 为 0～1 的路径长度比例，`x/y` 为页面方向的偏移；同一标签不能同时设置 `nodeId` 和 `edgeId`。
图元与端口来自现有 Python 工厂；导出前重新解析整个图纸，避免旧坐标缓存。
中文字体和字号效果以“正式预览”为准。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z |
| 保存 JSON | Ctrl+S |
| 复制选中设备、标签、三通 | Ctrl+D |
| 整体移动全部内容 | Ctrl+A，再拖动 |
| 多选对象 | Shift+点击 |
| 追加框选 | Shift+空白处拖动 |
| 删除选中对象及关联管线 | Delete / Backspace |
| 退出放置或连线 | Esc |
| 临时平移 | 空格+拖动或鼠标中键 |

一次完整拖动对应一次撤销。删除设备会同时删除附着标签和关联管路。

## 范围与交付

首版支持压缩机、换热器、电子膨胀阀、闪蒸罐、气液分离器（内部 U 型管）、中间换热器和三通。
Web 页面与服务随源码交付；Python wheel 包含图纸模型和 JSON 模板，尚不包含 Web 启动器和静态页面。
完整方案与验收记录见 [WEB_PROJECT_PLAN.md](../WEB_PROJECT_PLAN.md)。
