# rrplot 浏览器编辑器

使用仓库已有 Python 环境即可运行，无新增运行依赖，不需要 npm、Node.js 或构建前端。

## 启动

Windows 下可以双击仓库根目录的 `start-web.cmd` 启动。
使用编辑器期间请保持该窗口打开，关闭窗口或按 Ctrl+C 会停止服务。

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe server\run.py
```

打开 <http://127.0.0.1:8765>。更换端口可加 `--port 8766`。按 Ctrl+C 停止服务。
也可从其他目录用 Python 和 `server/run.py` 的绝对路径启动。
服务只绑定 `127.0.0.1`，适用于本机单用户，不需要数据库。

如果尚未安装项目依赖，请先按仓库 README 安装 rrplot；Web 端复用 Matplotlib 和 numpy。
直接通过 `file://` 打开页面无法调用绘图接口。
如果浏览器提示“拒绝连接”或“无法访问此网站”，先重新启动服务，再刷新页面。
网页文件存在并不表示本机 HTTP 服务正在运行。
同一端口只运行一个服务；重复运行 `start-web.cmd` 时，如果检测到已有 rrplot 服务，会直接提示服务地址。要加载代码或模板更新，请先在原服务窗口按 Ctrl+C，再重新运行脚本；如果端口被其他程序占用，可使用 `start-web.cmd --port 8766`。

## 编辑图纸

1. 左侧点击“模板”，选择普通热泵、带气液分离器的普通热泵、EVI 过冷器、FTVI 闪蒸罐、EVI 中间换热器或四通阀热泵（制热/制冷）模板，也可以新建空白图纸。
2. 点击图元库的设备，再点击画布放置；也可从图元库拖入画布。
3. 选择设备并拖动，或在属性面板输入坐标、尺寸、画法、方向和旋转角。
4. 切换“连线”工具，依次点击起点、终点端口或三通；选中起点后会显示虚线预览，靠近端口或三通会自动吸附。移动设备后，连线按端口重新计算。
5. 选中管线，拖动线段中间的长条手柄调整走线：水平段上下拖，垂直段左右拖，端口连接和引出段保持固定。双击管线增加方形折点，拖动折点改变路径；Alt+点击折点删除。
6. 三通工具可独立放置分支点；选择管线后，属性面板可在中间插入三通，再连接支路。
7. 选择模式下依次点两个端口，在左侧“端口对齐”中选择水平或垂直对齐，移动第二个对象。
8. 文字工具添加独立标签；设备属性可添加附着标签。设备附着标签随设备移动和旋转；选中管路后可“添加状态点”，让编号或参数文字随管路调整。标签支持拖动偏移、字号、对齐和白色背景。
9. 按住 Shift 点击多个设备、管路、三通或文字可多选；拖动已选设备、三通或文字按同一位移批量移动，管路按端点跟随。附着标签随设备移动，避免重复位移。
10. 多选后，属性栏“批量布局”提供左/中/右、上/中/下对齐，以及水平/垂直等距分布；每次操作可撤销。

连线和端点重接时，鼠标距端口或三通中心 12 个屏幕 CSS 像素以内即可吸附，
画布放大或缩小后仍保持相同的操作距离。起点、终点和重接共用此规则，
悬停预览与实际点击使用同一目标；直接点中接点优先，否则选择范围内最近的接点。
同一设备上重合的端口别名按一个物理端口处理。最近接点不可连接时显示原因，
不会跳过它连接到另一接点。“吸附”复选框只控制网格吸附，不关闭接点吸附；
选择模式不使用附近接点，空格拖动和鼠标中键仍优先平移视图。

连线和端点重接会在提交前检查：起终点位于同一位置时拒绝连接；端点及完整走线
与已有管路相同时提示重复，忽略箭头方向、线宽及颜色。相同端点但走线不同的并行管路可保留，
几何交叉或接触不会自动成为连接。需要分支时请使用明确的三通。
连接被拒绝后保留已选起点或重接状态，可直接选择其他端口/三通，或按 Esc 取消；
不修改图纸、草稿或撤销记录。旧图中已有的问题仍可用“检查”定位，本功能不会自动删除旧管路。
选好起点后，悬停端口或三通会显示目标名称与端口 ID，可连接时出现绿色圆环及“点击连接”提示；
同位置接点或重复走线显示红色圆环、红色虚线预览和原因。端点重接使用相同提示，
原端口可点击返回而不修改图纸。移开接点恢复普通虚线预览，离开画布或按 Esc 清除标记。
悬停只检查当前几何连接，不验证制冷剂流向或热力工况，点击时仍会再次校验。

图元库现有 11 种图元。在“搜索图元”输入中文名称或英文类型可筛选，支持空格分隔多个关键词、
英文大小写与全半角；筛选不会删除图元或改变图纸。左侧“图元 / 模板 / 对象”可分别打开三个面板。
“模板”面板现有 7 个系统模板，输入中文名称或英文 ID 搜索，支持多个关键词、英文大小写与全半角。
切换面板和搜索不修改图纸或撤销记录；载入模板前，未保存的修改会通过页面弹窗提示。

四通阀热泵的两套模板共用设备位置和外部接管，用箭头、室内外换热器角色及阀内连通文字区分工况。
制热为 D→C、E→S，室内冷凝、室外蒸发；制冷为 D→E、C→S，室外冷凝、室内蒸发。
D（`exhaust`）固定接压缩机排气，S（`suction`）经 U 型管气液分离器回压缩机吸气。
C（`condenser`）固定接室内换热器，E（`evaporator`）固定接室外换热器；端口 ID 为图元命名，
换向后不会随实际冷凝/蒸发角色交换。模板采用双向节流和过滤示意，不包含除霜控制及完整阀组。
阀内连通文字是可编辑标签，旋转或编辑图元不会自动改变工况；更换工况请载入对应模板。

新增常用管路图元及其端口：

| 图元 | 端口与可编辑参数 |
| --- | --- |
| 四通换向阀 | `exhaust` 为 D 排气口，`suction` 为 S 回气口，`condenser` / `evaporator` 为 C / E 两侧换热器接管；可改半径及 D/C/E/S 口标开关 |
| 截止阀 | `in` / `out` 默认左进右出；可改阀体宽高、阀杆长度和手轮宽度 |
| 电磁阀 | `in` / `out` 默认左进右出；可改半径、引线长度和线圈横杠宽度 |
| 单向阀 | 三角尖端指向 `out`，`point=e` 向右、`point=w` 向左；可改阀体宽高与接管长度 |
| 过滤器 | `in` / `out` 默认左进右出；可改宽高、接管长度与网格线数（3～25 的整数） |

以上图元复用 Python 图元库，支持放置、拖动、90 度旋转、端口连接、复制删除、撤销重做、JSON 保存与正式出图。
修改尺寸后接管与管路同步更新；单向阀切换方向会交换 in/out 的物理位置，已有管路按原端口 ID 跟随。
四通阀的口标随图元整体旋转，新放置时名称标签留在口标外侧；图元不模拟阀芯切换或实际流动状态。
选中框与图纸检查的边界包含接管、阀杆、手轮和口标。

新增图元及模板需要新版 Python 服务：先保存当前 JSON，在原服务窗口按 Ctrl+C 停止，再运行 `start-web.cmd`，
最后在浏览器按 Ctrl+F5。图元库应显示“共 11 种图元”，“模板”面板应显示“共 7 个模板”；数量未更新时请确认旧服务已停止并重新启动。

点击“框选”，在画布拖出矩形，可一次选中完整框住的设备、管路、三通和文字，向任意方向拖框均可。
管路按完整走线判断，起终点和全部折弯都须在框内；只穿过矩形的管路不会选中。
松开后自动回到“选择”，可批量改样式或删除；拖动已选设备、三通和文字可一起移动，或在属性栏对齐、均匀分布。
选择模式下按住 Shift 从空白处拖动可追加框选，Shift+点击可取消某一项。
框选期间按 Esc 恢复原选择；框选不会移动视图或修改图纸，也不占用撤销记录。

在画布或“对象”列表中，Shift+点击管路可逐条追加或取消选择，也可与设备、三通和文字混选。
多选后点击“批量样式”，范围选“当前选择”，即可统一选中管路及其状态点的外观；删除会同时移除这些管路的状态点，可一次撤销。
多选时隐藏单管的折点和线段手柄。要编辑单条走线，先点画布空白清除选择，再点击目标管路；Shift+双击不会新增折点。
单独选中的管路不参与对齐、分布或直接拖动；移动设备时仍按原端口连接跟随。
只选管路时禁用“复制”和“副本”，复制管路请同时选择其两端设备或三通。

单选或多选管路后，右侧“管路操作”显示直接选中的管路数量：

- “反转流向”交换各管路起终点，保留原有走线、样式和状态点页面位置；设备及端口位置保持不变。
- “清除折点”删除这些管路的手动顶点，恢复按端口自动走线；状态点保留路径比例与偏移，沿新走线跟随。所选管路均无手动折点时按钮禁用。

两项操作仅处理直接选中的管路，不会因选中设备而自动扩展到关联管路，也不改变设备的实际流通方向参数。
整批对应一次撤销/重做；成功后保留选择，任一管路无法处理时整批保持原样。连线、放置、重接或拖动期间不可执行。
本次仅更新前端，保存当前 JSON 后按 Ctrl+F5 加载即可，无需重启服务。

多选后点击“副本”或按 Ctrl+D，会向右下偏移 20 单位复制整组对象，包含设备附着标签，
以及两端均在组内的管路和手动折点。副本保持选中，可直接整组拖动；组内折点随对象一起移动。
单独复制旋转设备上的标签时，标签保持附着，按页面的右下方向偏移。
点击“删除”或按 Delete / Backspace 删除全部选择，同时清理被删设备的标签和关联管路。
删除管路中间的两接管三通会恢复管路；删除仍有三条及以上接管的三通会移除这些关联管路。
一次复制或删除对应一次撤销，可用 Ctrl+Z / Ctrl+Y 撤销或重做。

## 跨图纸复制粘贴

选择设备、三通或文字，点击“复制”或按 Ctrl+C，存入当前页面的编辑器剪贴板。
可先切换系统模板、打开 JSON 或新建空白图纸，再点击“粘贴”或按 Ctrl+V。
剪贴板保存复制时的快照，之后移动或删除原对象不会改变已复制的内容。
复制不修改图纸、不增加撤销记录；替换图纸仍会提示保存当前修改。

复制设备时会带上设备标签；两端设备或三通均在选择内的管路、折点和管路状态点一起复制。
跨组连线不复制。单独复制附着标签或状态点时，转为独立文字并保留页面位置和样式，
避免绑定到目标图纸中的同名设备或管路。单独选中的管路暂不支持复制，请选择其两端设备或三通。

首次粘贴相对原坐标向右下偏移 20 单位，重复粘贴继续偏移，每次都生成新的对象 ID。
切换图纸后首次偏移重新从 20 单位开始。目标图纸名称和页面尺寸保持原值，
粘贴后的对象保持多选，可直接整组拖动或用方向键微调；一次粘贴对应一次撤销或重做。
超出页面时可用“页面排版”中的“页面适配内容”整理纸张，再用“检查”核对；超过对象数量或坐标上限时，整次粘贴不生效。

编辑器剪贴板仅用于当前页面内的图纸之间，刷新或关闭页面后清空，不读写系统剪贴板，也不会写入 JSON 或草稿。
输入框中的 Ctrl+C / Ctrl+V 保留文字复制粘贴；放置、连线、重接和拖动期间请先完成操作或按 Esc。
本次为前端更新，保存 JSON 后按 Ctrl+F5 加载即可。

U 型管气液分离器的 `in` 为顶部短管入口，`out` 为 U 型管出口，
`drain` 为底部排液口。属性中的“镜像进出管”可交换左右进出管位置，
“接管长度”同时更新外形和端口。带气液分离器模板将出口与压缩机吸气口垂直对齐。

窄窗口中用工具栏的“图元”和“属性”打开侧栏，再次点击关闭。滚轮缩放，空白拖动平移，
“适应页面”恢复整页视图；按住空格或鼠标中键也可平移。网格显示与网格吸附可分别开关。
“网格”和“吸附”在窄窗口中也可操作，默认均开启；各自记住最后选择，刷新后恢复。
设置仅保存在相同浏览器与服务地址，不写入图纸 JSON，不产生撤销记录或未保存标记；
网格显示不影响吸附，关闭网格仍可保持吸附。浏览器禁止本机存储时，当前页面仍能切换，
保存失败会提示刷新后重新检查；读取失败使用默认开启。更换浏览器、端口或清除站点数据后需重新设置。
侧栏从完整工具栏下方展开，工具栏换行或浏览器缩放后自动调整位置。顶部按钮超出宽度时
可横向滚动访问，也可用 Tab 依次聚焦；按钮保留原有大小。
窗口高度较小时，工具栏最多占工作区一半高度，可在工具栏内上下滚动查看后续按钮，
给画布和侧栏保留空间。正常高度下工具栏仍按内容展开。

要改变整张系统图在纸面中的位置，点击“整体移动”（或在非输入框中按 Ctrl+A），
在画布任意位置按住左键拖动。设备、三通、管路折点和文字同步移动，连接关系与相对布局保持不变。
吸附开启时按统一位移吸附，关闭后可自由移动。每次拖动对应一次撤销，可用 Ctrl+Z / Ctrl+Y 撤销或重做。
拖动中按 Esc 取消本次移动；松开后按 Esc 或点击“选择”退出。纸张和视图位置不变，保存与导出会保留移动结果。

## 批量样式

点击画布工具栏“批量样式”，或多选后的属性栏同名按钮，统一管路或标签的外观。
先选择“当前选择”或“整张图纸”，面板会显示将处理的管路和标签数量。

- 当前选择：包含直接选中的管路或标签；所选设备附带设备标签，两端设备或三通均在组内的管路及其状态点也包含在内。跨组管路保持原样。
- 整张图纸：包含全部管路、设备标签、独立文字和管路状态点。

勾选要修改的项目，再设置新值；未勾选的项目保留各自原值。
管路可设置颜色、线宽（0.2～8 pt）、实线/虚线和流向箭头；标签可设置颜色、字号（6～72 pt）、文字对齐和白色背景。
“当前值不一致”表示这些对象原有样式不同；勾选后会统一成输入的新值。
切换范围会清空本次设置，取消或按 Esc 不修改图纸。

一次有效应用对应一次撤销/重做，保持坐标、连接、折点、箭头位置、文字内容和附着关系。
重复应用相同样式不增加历史；未勾选任何项目或范围内没有管路/标签时不能应用。
结果保存到草稿和 JSON，并用于正式预览和导出；放置、连线、重接、拖动和页面排版计算期间请先完成当前操作。
本次仅更新前端，保存 JSON 后按 Ctrl+F5 加载，无需重启服务。

## 页面排版

点击画布工具栏“页面排版”，右侧打开页面设置；窄窗口也会直接展开属性面板。
排版作用于整张图纸，包括设备、三通、设备标签、独立文字、管路状态点和管路折点。

- “内容居中”：保持当前纸张尺寸，整体移动内容，使四周剩余空间居中；内容大于纸张时会提示先适配页面。
- “页面适配内容”：按内容范围重新计算纸张宽高，将整图移入页面，并在四周保留指定留白。
  “适配留白”默认为 40 单位，可设为 10～500；纸张宽高取整数，范围为 100～4000，最小纸张可能产生更多留白。

两种操作都不缩放图元，保持设备参数、端口连接、附着标签的相对偏移和管路样式。
每次有效排版对应一次撤销/重做，结果写入草稿和 JSON，并用于正式预览与导出。
仅修改留白设置不会修改图纸或增加历史；留白设置保留在当前页面内，刷新后恢复默认值。
重复应用相同排版不增加历史。空图纸禁用排版，适配超过尺寸上限或计算期间图纸发生变化时不应用结果。

“适应页面”只调整缩放和平移视图；“页面排版”会改变内容坐标，适配时还会改变纸张尺寸。
文字范围以当前字体测量，使用固定比例测量避免画布缩放引起排版偏移；正式效果仍可通过顶部“预览”核对。
本次为前端更新，保存 JSON 后按 Ctrl+F5 加载即可，无需为本轮改动重启服务。

管线交叉不代表连通；使用显式三通建立支路。路由保持直角并沿端口法向引出，
目前不会自动绕开设备，复杂管路需要手动控制点。编辑器不进行制冷循环或热力正确性计算。

线段拖动遵循“吸附”开关，直管移动后自动增加直角折弯。过短线段和固定端口引出段不显示长条手柄。
每次拖动对应一次撤销；拖动中按 Esc 取消，属性栏的“清除折点”可恢复自动走线。

## 保存、预览与恢复

- “保存 JSON”保存可再次编辑的完整图纸。支持原生保存窗口的浏览器会让你选择位置，文件写入完成后才清除未保存标记和当前草稿；取消或失败会保留修改与草稿。每次保存均选择目标文件，不会静默覆盖。
- 不支持原生保存窗口时，使用浏览器下载，并显示“确认已保存 / 暂不确认”。检查 JSON 文件已保存后再确认；确认前保留未保存标记和草稿。“暂不确认”仅收起提示，后续可重新保存。
- 保存期间按钮显示“保存中…”并阻止重复提交。保存的是点击时的快照；期间继续修改或替换图纸，当前图纸不会被旧保存结果标为已保存，下载确认提示也会随新修改失效。
- “打开 JSON”从本机恢复，非法图纸会显示原因并保留当前图纸。
- 新建、打开 JSON 和载入模板共用载入保护，先确认未保存修改，再读取并校验目标图纸。载入提示显示目标名称，可点“取消载入”；继续编辑、输入图纸属性或撤销重做会取消旧载入，保留当前修改。快速切换时只允许最近一次载入生效，同一模板等待期间重复点击不重复请求。
- 载入失败保留当前图纸、草稿和撤销记录。拖动、放置、连线、重接或页面排版期间请先完成操作或按 Esc；弹窗打开时不能开始另一项载入。取消会忽略后续结果，已经发出的本机请求可能仍会完成。
- “正式预览”调用 rrplot/Matplotlib 输出整图；PNG、SVG、PDF 使用同一输出模型，不带网格、端口和选中框。
- 修改后自动写入当前浏览器的本机草稿。顶部“草稿”可随时查看名称、保存时间及设备/管路数量，并选择恢复；启动提示中的“暂不恢复”只收起提示，仍可从顶部进入。
- 首次编辑会在覆盖上次会话或其他标签页的草稿前，将其放入历史，最多保留最近 5 份历史草稿及当前自动草稿，相同内容去重。连续编辑当前图纸不会每次生成历史；超出 5 份时淘汰最早的历史。恢复前校验图纸，失败保留当前图纸；恢复成功后仍需保存 JSON。
- 草稿仅在相同浏览器和服务地址中可用，更换端口或浏览器会使用不同存储。草稿不会上传云端，且不替代 JSON 文件备份；存储不可用或空间不足时显示“草稿未保存”，保留原有草稿，请立即保存 JSON。
- 有未保存修改时，替换图纸或关闭页面会提示。草稿的可用性取决于浏览器存储，清理浏览器数据会删除草稿。
- 当前修改成功写入 JSON、确认下载已保存或确认替换图纸后，只清除当前页面自己记录的自动草稿，历史草稿保留；替换确认中选择“继续编辑”可保留当前修改。启动时尚未恢复的草稿及其他标签页新写入的草稿，不会被保存或切换模板操作直接清除。恢复历史草稿时，现有自动草稿也会先进入历史。

## 图纸检查

- 端点和完整走线均相同的管路，忽略流向与样式；端点相同、走线不同的并行管路允许保留。

设备的备用端口不要求全部接管；两个接管的三通允许作为管路中的过渡点。端口别名按同一物理接管处理。
