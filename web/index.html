编辑临时折点坐标

按起点到终点的顺序填写图纸坐标，X 向右、Y 向下为正，支持小数，不受网格吸附影响。

批量粘贴坐标

可粘贴表格中的两列，或用逗号、空格分隔 X/Y；每行一个折点，最多 100 个。载入会替换窗口内列表，点击“应用坐标”后才生效。

复制折点坐标

复制当前列表的 X/Y 两列，保留顺序和小数；仅包含手动折点，不包含起终端口。未应用的输入也可复制。

应用后继续连线，最终完成时随整条管路保存和撤销；取消或 Esc 保留原折点。
精确平移

使用图纸坐标单位，支持小数，不受网格吸附影响。设备附着标签和组内管路随组移动；跨组管路按端点跟随。单独选择管路不会平移走线。

保持纸张和视图位置。应用后可用 Ctrl+Z 一次撤销。
帮助与快捷键

点击画布后使用单键快捷键；输入框、输入法组合和弹窗内保留原有按键。进行中的放置、连线、重接或拖动请先完成，或按 Esc 取消。

开始绘图

  1. 从左侧“模板”载入系统，或新建后在图元库选择设备并点击画布放置。
  2. 使用“连线”，依次点击设备端口或三通；靠近接点会吸附并显示走线预览。移动设备或编辑折点请先切回“选择”；连线时拖动空白只平移视图，保留已选起点。
  3. 选中对象后在右侧修改参数、文字和样式；Shift+点击可多选，拖动已选设备可整组移动。
  4. 保存 JSON 以便继续编辑；“预览”和“导出”生成正式图，不包含网格、端口与选中框。

鼠标与精确编辑

  • 滚轮缩放；拖动空白平移视图。按住空格拖动或使用中键，可临时平移。
  • 框选需完整框住对象；Shift+空白处拖动追加框选，Shift+点击追加或取消选择。
  • 单选管路后，点击两端圆圈再点新端口或三通可重接，也可 Shift+点击其他管路，自动插入三通并重接；拖动长条手柄调整线段，双击增加折点，Alt+点击方形折点删除。
  • 使用“三通”工具悬停管路，可预览插入圆环与坐标；绿色可插入，红色显示原因，点击完成插入。空白处可独立放置。管路属性可在中间插入三通、重接端点和添加状态点；属性栏“选择相连对象”扩展整个设备组。
  • 三通工具下 Shift+点击管路，可插入三通并立即选为支路起点，再点击终点即可。属性栏也有“插入三通并接出支路”和“从此三通接出支路”。Esc 取消连线时保留三通；插入和接管分别可撤销。
  • 连线起点已选或正在重接端点时，按住 Shift 悬停目标管路可预览接入位置，Shift+点击会插入三通并接好，整次操作可一次撤销。附近已有端口或三通时优先复用；普通点击管路不接入，不能重接到自身。
  • 连线工具尚未选起点时，也可 Shift+点击管路插入三通并作为起点，再点端口或 Shift+点击另一管路完成支路。插入与接管分别撤销；Esc 取消连线会保留已插入三通。
  • 新连线选好起点后，Alt+点击画布空白指定折点，Backspace 回退最后一个；再点击端口或三通，也可 Shift+点击管路完成。折点遵循网格吸附，最多 100 个，完成时整条支路一次撤销；Esc 取消未完成折点。端点重接继续保留原管路折点。
  • 新连线中的小方框可拖动调整，Alt+点击可删除指定折点。拖动时 Esc 恢复本次拖动并保留连线，再按 Esc 取消连线；调整和删除临时折点不增加撤销记录。
  • 选好起点后，上方操作栏显示临时折点数量，可点击“回退折点”“清空折点”或“取消连线”。清空保留起点并恢复自动走线，取消保留已插入的三通，可 Ctrl+Z 撤销插入。
  • 已添加折点后，点击“编辑坐标”可输入每个折点的 X/Y，支持小数，不受网格吸附影响。“应用坐标”只更新当前连线，取消或 Esc 保留原折点；越界或相邻重合时提示原因并保留窗口供修改。
  • 已有管路也可精确编辑：单选管路后，在属性栏点击“编辑折点坐标”。没有手动折点也能直接添加。坐标窗口支持末尾添加、在指定折点前插入和删除，最多 100 点；全部修改在“应用坐标”后生效，删空后恢复自动走线。已有管路可 Ctrl+Z 一次撤销，端口和样式保留，状态点沿新走线跟随；取消或 Esc 放弃本次输入与增删。
  • 坐标窗口每行“上移 / 下移”可调整折点顺序，保留未应用的输入，自动重新编号；第一行不可上移，最后一行不可下移。排序与增删、坐标修改一起应用，取消或 Esc 放弃本次修改。
  • 坐标窗口标题与底部操作固定显示，中间说明、预览和折点列表统一滚动；长列表仍可随时取消或应用，无需滚到底部。
  • 底部“清空列表”一次移除窗口中的全部折点；“恢复原坐标”恢复本次打开窗口时的数量、顺序和坐标。两者仅修改待应用内容，取消或 Esc 放弃修改；清空后应用恢复自动走线。已经应用的修改可用 Ctrl+Z 撤销。
  • 坐标或几何校验失败时，首个出错折点显示行内原因并标红相关输入。点击“应用坐标”自动定位该输入，修正后清除提示；重复走线及图纸变化等整体问题只在窗口提示。
  • 坐标窗口的预览折点可点击定位到对应 X 输入，支持 Tab 选点后 Enter / 空格定位；聚焦坐标输入时，对应列表行和预览折点同步高亮。
  • 坐标窗口底部的“上一折点 / 下一折点”按列表顺序定位，也可从“定位到折点”列表直接跳转。定位聚焦 X 输入，保留所有未应用修改；预览无效时仍可定位其他折点。
  • 坐标窗口“撤销输入 / 重做输入”恢复尚未应用的坐标、增删、排序、清空和恢复操作；同一输入框连续输入合并为一步，最多保留 100 步。新修改清除重做，取消或应用后清空窗口历史；已应用的管路修改仍用画布 Ctrl+Z 撤销。
  • 展开“批量粘贴坐标”，粘贴表格两列或每行用逗号、空格分隔的 X/Y，点击“载入坐标列表”替换窗口内折点（最多 100 个）。全部校验通过才载入，可“撤销输入”恢复，点击“应用坐标”后才改动管路；空文本不会清空列表。
  • 展开“复制折点坐标”，点击“复制坐标”，把当前列表复制为可粘贴到表格的 X/Y 两列，不含起终端口。复制保留未应用的小数输入；空值或越界需先修正。自动复制不可用时，文本会选中，按 Ctrl+C 即可；修改列表后需重新复制。
  • 坐标窗口内灰线为原走线、绿线为新走线，输入、增删或排序后实时更新；输入无效时提示原因，修正后恢复。已有管路预览完整路径，临时连线仅预览至最后折点，终点待选。此为局部走线示意，预览不改变图纸、草稿、历史或画布视图。
  • 三通工具和 Shift 接管时，靠近管路 12 个屏幕像素内即可吸附；缩放不改变操作距离。直接点中的管路优先，否则选择最近管路；点中设备或文字不会误插三通。
  • 三通工具靠近已有三通时，点击选中，Shift+点击直接接出支路；设备端口附近显示红色提示，请使用“连线”。不会重复插入三通，网格落点重合也有保护。
  • “精确平移”输入 X/Y 位移；多选属性提供对齐、均匀分布和批量样式。

视图、纸张与保存

  • “适应页面 / 适应内容 / 定位所选”只改变视图；“页面排版”用于移动内容或调整纸张尺寸。
  • “草稿”可恢复当前浏览器与服务地址的本机记录；需要文件备份时请保存 JSON。
  • PNG、SVG 和 PDF 用于出图，不替代可编辑 JSON；导出不会清除未保存标记。
