rrplot 文档
==============

制冷循环 / HVAC 示意图绘制库:坐标式部件拼装 + 走线式连管,
输出 PNG / PDF / SVG。

从这里开始:

- :doc:`tutorial` —— 从零画出一张循环图,含部件速查与排错
- :doc:`design` —— 坐标系、端口法向、走线算法为什么这么设计
- :doc:`api` —— 全部模块与函数的自动提取参考

安装方式见仓库 ``README.md``,或::

    pip install -e .
