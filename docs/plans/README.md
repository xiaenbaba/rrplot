## 维护约定

- 路线图负责说明先做什么、做到哪里；新增详细过程、测量和验收记录写入
  对应专项计划，从路线图链接过去，避免重复维护同一状态。已有记录保留。
- 新专项计划建议使用清晰的英文主题名，例如 `automatic-routing.md`，正文
  注明日期、目标、范围、实施顺序、验收条件和当前状态。
- 已替代或停止维护的计划可移入 `archive/`；有归档内容时再创建该目录，
  更新本索引和所有相对链接。
- 现行架构维护在 [ARCHITECTURE.md](../ARCHITECTURE.md)，历史问题与复审结论
  放在 [review/](../../review/README.md)，已交付变化记入 [CHANGELOG.md](../../CHANGELOG.md)。
